## 写入纪律

1. **只追加，不改历史行**：新决定按日期升序追加一行；被取代的旧结论在原「决定」列内标注「（已被 YYYY-MM-DD 修正：…）」，不删行。
2. **日期 = 拍板日期**，不是实现日期。
3. **`基线影响` 列必须写影响面**：无影响写「无（……）」，有位移写明重录范围。
